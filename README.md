# skillinjection.com

A plain-language reference page defining **skill injection** — an attack class
where a malicious agent *skill file* smuggles hidden instructions into an LLM
agent's execution context, run with the agent's own permissions.

**Live site:** https://skillinjection.com

The page covers the definition, the mechanism, how skill injection differs from
prompt injection / supply-chain / tool poisoning, and links to the primary
research (arXiv).

**Related attack class:** [sleeper attack](https://sleeperattack.com) — a
planted instruction that lies dormant in an LLM agent's memory and triggers
later on an unrelated event.
